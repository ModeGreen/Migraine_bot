# Migraine bot — дневник головной боли в Telegram

Бот, который помогает вести дневник мигреней:

- **регулярно спрашивает**, болела ли голова с прошлого опроса (частота и время настраиваются в боте);
- если болела — задаёт **вопросы с кнопками**: где болело, шли ли месячные, сколько длилось, сила боли 1–10, принимала ли обезболивающее;
- в конце принимает **свободный рассказ** — сколько угодно сообщений и **голосовых** (они расшифровываются в текст прямо на сервере, голос никуда не отправляется);
- приступ можно записать **сразу**, не дожидаясь опроса — кнопка «🤕 Записать приступ»;
- **выгружает дневник** за неделю, месяц или всё время в Markdown-файл, который удобно отдать нейросети или врачу, и в CSV для таблиц.

Данные хранятся только у вас на сервере: SQLite-база и голосовые лежат в папке `data/`, каждый день делается бэкап базы в `data/backups/` (хранятся последние 14).

## Что нужно

- Linux-сервер (или любой компьютер, который всегда включён) с Docker и Docker Compose.
- Для расшифровки голосовых: ~2 ГБ свободной RAM в момент расшифровки для модели `medium` (или ~1 ГБ для `small`). Всё остальное время бот занимает около 100 МБ: модель загружается при первом голосовом и выгружается после 10 минут простоя.
- Место на диске: ~1,5 ГБ под модель `medium`.

## Установка

1. **Создайте бота** у [@BotFather](https://t.me/BotFather): команда `/newbot`, придумайте имя — получите токен вида `123456:ABC...`.

2. **Скачайте проект** на сервер:
   ```bash
   git clone https://github.com/ModeGreen/Migraine_bot.git
   cd Migraine_bot
   cp .env.example .env
   chmod 600 .env          # токен бота виден только вам
   mkdir -p data && chmod 700 data
   ```
   Если `id -u` выдаёт не `1000`, впишите свои значения `id -u` / `id -g` в `PUID` / `PGID` в `.env`.

3. **Заполните `.env`**: впишите `BOT_TOKEN`. `ALLOWED_USER_IDS` пока можно оставить пустым.

4. **Запустите**:
   ```bash
   docker compose up -d --build
   ```

5. **Узнайте Telegram ID**: напишите боту что угодно — он ответит, что доступа нет, и покажет ID. Впишите его в `.env` (`ALLOWED_USER_IDS=123456789`, несколько — через запятую) и перезапустите:
   ```bash
   docker compose up -d
   ```

6. Напишите боту `/start`. Бот спросит часовой пояс — проще всего отправить геопозицию (по ней определяется только пояс, офлайн, координаты не сохраняются), или выбрать город из списка, или написать, сколько сейчас времени. Готово! По умолчанию опрос каждый день в 21:00, поменять можно в «⚙️ Настройки».

Часовой пояс сервера значения не имеет: у каждого пользователя свой, его можно сменить в настройках, например в поездке.

## Как пользоваться

Весь интерфейс — **одно сообщение-меню**, которое меняется при нажатии кнопок. Сообщения пользователя (ответы, заметки, голосовые) сохраняются в дневник и сразу удаляются из чата, так что мусор не копится. В чате остаются только меню и файлы выгрузки. Из любого раздела есть «⬅️ Назад» и «🏠 Меню»; открыть меню заново — `/menu`.

| Кнопка главного меню | Что делает |
|---|---|
| 🤕 Записать приступ | Начать запись прямо сейчас |
| 📤 Выгрузка | Файл с дневником за неделю / месяц / всё время, или CSV-таблица |
| ⚙️ Настройки | Частота и время опросов, часовой пояс, пауза, «спросить сейчас», удалить последнюю запись |
| ❓ Как пользоваться | Короткая справка |

- Опрос приходит отдельным сообщением (чтобы было уведомление) и заменяет собой меню.
- На вопросы можно отвечать кнопками или просто написать ответ текстом/голосом. Силу боли можно сказать словами: «где-то семь».
- «⬅️ Назад» внутри записи возвращает к предыдущему вопросу; запись можно прервать кнопкой «🏠 Меню» и продолжить позже.
- Голосовое без начатой записи само начинает новую запись и сохраняется в её заметки.
- Любой вопрос можно пропустить.
- На последнем шаге пишите и надиктовывайте сколько угодно, потом нажмите «✅ Готово — сохранить запись». Если забыть — запись закроется сама через час тишины (`NOTES_AUTOCLOSE_MINUTES`).
- «⏰ Спроси позже» в опросе — повторит вопрос через 2 часа (`SNOOZE_MINUTES`).

### Анализ в нейросети

Выгрузите дневник (`.md`) и отправьте файл в ChatGPT / Claude / Gemini с просьбой, например:

> Проанализируй дневник головной боли: частота и сила приступов, возможные триггеры, связь с менструальным циклом, эффективность обезболивающих, сколько дней в месяц принимались обезболивающие. Что стоит обсудить с неврологом?

Нейросеть — не врач: результат стоит обсудить со специалистом.

## Настройка вопросов

Вопросы лежат в [`questions.yaml`](questions.yaml) — их можно менять, добавлять и удалять без правки кода. Типы: `single` (один вариант), `multi` (несколько), `scale` (шкала чисел). После правки:

```bash
docker compose restart
```

Не меняйте `id` у вопросов, на которые уже есть ответы, — иначе в выгрузке старые ответы потеряют подпись.

## Все параметры `.env`

| Параметр | По умолчанию | Описание |
|---|---|---|
| `BOT_TOKEN` | — | Токен от @BotFather (обязательно) |
| `ALLOWED_USER_IDS` | — | Telegram ID через запятую, кому разрешено пользоваться |
| `WHISPER_MODEL` | `medium` | `tiny` / `base` / `small` / `medium` / `large-v3` / `off` |
| `WHISPER_LANGUAGE` | `ru` | Язык голосовых |
| `WHISPER_UNLOAD_MINUTES` | `10` | Через сколько минут простоя выгружать модель из памяти |
| `NOTES_AUTOCLOSE_MINUTES` | `60` | Автозакрытие записи, если не нажали «Готово» |
| `SNOOZE_MINUTES` | `120` | Через сколько повторить опрос после «Спроси позже» |
| `TZ` | пояс сервера | Пояс по умолчанию, пока пользователь не указал свой. Например `Europe/Moscow` |

У каждого пользователя из `ALLOWED_USER_IDS` свой отдельный дневник, свой часовой пояс и свои настройки опросов.

## Ручная установка модели Whisper

Бот сам скачивает модель с huggingface.co при первом запуске (в логах: `Скачиваю модель Whisper…` → `Модель Whisper готова`). Если сеть сервера не пускает к huggingface.co или качает очень медленно, скачайте 4 файла на любом компьютере, где сайт открывается:

```
https://huggingface.co/Systran/faster-whisper-medium/resolve/main/config.json
https://huggingface.co/Systran/faster-whisper-medium/resolve/main/model.bin
https://huggingface.co/Systran/faster-whisper-medium/resolve/main/tokenizer.json
https://huggingface.co/Systran/faster-whisper-medium/resolve/main/vocabulary.txt
```

(для другой модели замените `medium` на `small` и т. п.) и положите их на сервер в `data/models/faster-whisper-medium/`, например:

```bash
scp config.json model.bin tokenizer.json vocabulary.txt user@server:Migraine_bot/data/models/faster-whisper-medium/
```

Бот подхватит модель сам, перезапуск не нужен. Голосовые, присланные до этого, расшифруются автоматически.

## Обслуживание

```bash
docker compose logs -f --tail 100   # логи
git pull && docker compose up -d --build   # обновление
```

Бэкап — это просто папка `data/` (база в `data/diary.sqlite3`, ежедневные копии в `data/backups/`).

## Безопасность и приватность

Что сделано в боте:

- **Белый список**: бот работает только с Telegram ID из `ALLOWED_USER_IDS`, остальным отвечает отказом (не чаще раза в час).
- **Только личные сообщения**: в группах и каналах бот молчит, чтобы дневник никогда не попал в общий чат.
- **Голос не покидает сервер**: расшифровка локальная. Модель Whisper один раз скачивается с Hugging Face.
- **Геопозиция не хранится**: по ней сразу определяется часовой пояс офлайн, сохраняется только его название.
- Данные кнопок проверяются: подделанный запрос не может изменить чужую запись или сломать расписание.
- Контейнер работает **не от root**, без лишних привилегий (`cap_drop: ALL`, `no-new-privileges`).
- Папка `data/` и `.env` доступны только владельцу; `.env` и `data/` исключены из git.

Что важно понимать:

- **Telegram — не сквозное шифрование** для ботов: сообщения проходят через серверы Telegram, как и любая переписка с ботом.
- **База на диске не зашифрована.** Защищайте сервер: вход по SSH-ключу, обновления, при желании — шифрование диска. Бэкапы в `data/backups/` содержат те же данные.
- **Выгрузку отправляете вы сами.** Отдавая файл нейросети, вы передаёте медицинские данные её владельцу — учитывайте их политику хранения данных.
- **Токен бота = полный доступ к боту.** Не публикуйте `.env`. Если токен утёк — `/revoke` у @BotFather и новый токен в `.env`.
- Рекомендуется у @BotFather выполнить `/setjoingroups` → **Disable**, чтобы бота нельзя было добавить в группу.

## Запуск без Docker

```bash
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
set -a && . ./.env && set +a
python -m bot.main
```

## Устройство

```
bot/
  main.py        — запуск, регистрация обработчиков
  handlers.py    — диалог: опросы, вопросы, заметки, настройки, выгрузка
  schedule.py    — расписание опросов, автозакрытие записей, бэкапы
  transcribe.py  — расшифровка голосовых (faster-whisper, ленивая загрузка)
  export.py      — выгрузка в Markdown и CSV
  db.py          — SQLite
  questions.py   — чтение questions.yaml
  tz.py          — часовые пояса пользователей
  config.py      — настройки из .env
```
