# Migraine bot — дневник головной боли в Telegram

Бот, который помогает вести дневник мигреней:

- **регулярно спрашивает**, болела ли голова с прошлого опроса (частота и время настраиваются в боте);
- если болела — задаёт **вопросы с кнопками**: где болело, шли ли месячные, сколько длилось, сила боли 1–10, принимала ли обезболивающее;
- в конце принимает **свободный рассказ** — сколько угодно сообщений и **голосовых** (они расшифровываются в текст прямо на сервере, голос никуда не отправляется);
- приступ можно записать **сразу**, не дожидаясь опроса — кнопка «🤕 Записать приступ»;
- **выгружает дневник** за неделю, месяц или всё время в Markdown-файл, который удобно отдать нейросети или врачу, и в CSV для таблиц.

Данные хранятся только у вас на сервере: SQLite-база и голосовые лежат в папке `data/`, каждый день делается бэкап базы в `data/backups/` (хранятся последние 14).

## Что нужно

- Linux-сервер (или любой компьютер, который всегда включён) с Docker и Docker Compose.
- Для расшифровки голосовых: ~2 ГБ свободной RAM в момент расшифровки для модели `medium` (или ~1 ГБ для `small`). Всё остальное время бот занимает около 100 МБ: модель загружается при первом голосовом и выгружается после 10 минут простоя.
- Место на диске: ~1,5 ГБ под модель `medium`.

## Установка

1. **Создайте бота** у [@BotFather](https://t.me/BotFather): команда `/newbot`, придумайте имя — получите токен вида `123456:ABC...`.

2. **Скачайте проект** на сервер:
   ```bash
   git clone https://github.com/ModeGreen/Migraine_bot.git
   cd Migraine_bot
   cp .env.example .env
   ```

3. **Заполните `.env`**: впишите `BOT_TOKEN`. `ALLOWED_USER_IDS` пока можно оставить пустым.

4. **Проверьте часовой пояс сервера** — по нему приходят опросы:
   ```bash
   timedatectl
   ```
   Если там `UTC`, а вы живёте не по Гринвичу — либо смените пояс сервера (`sudo timedatectl set-timezone Europe/Moscow`), либо впишите `TZ=Europe/Moscow` в `.env`.

5. **Запустите**:
   ```bash
   docker compose up -d --build
   ```

6. **Узнайте Telegram ID**: напишите боту что угодно — он ответит, что доступа нет, и покажет ID. Впишите его в `.env` (`ALLOWED_USER_IDS=123456789`, несколько — через запятую) и перезапустите:
   ```bash
   docker compose up -d
   ```

7. Напишите боту `/start` — готово. По умолчанию опрос каждый день в 21:00, поменять можно в «⚙️ Настройки».

## Как пользоваться

| Кнопка | Что делает |
|---|---|
| 🤕 Записать приступ | Начать запись прямо сейчас |
| 📤 Выгрузка | Файл с дневником за неделю / месяц / всё время, или CSV-таблица |
| ⚙️ Настройки | Частота и время опросов, пауза, «спросить сейчас», удалить последнюю запись |

- На вопросы можно отвечать кнопками или просто написать ответ текстом/голосом.
- Любой вопрос можно пропустить.
- На последнем шаге пишите и надиктовывайте сколько угодно, потом нажмите «✅ Готово». Если забыть — запись закроется сама через час тишины (`NOTES_AUTOCLOSE_MINUTES`).
- «⏰ Спроси позже» в опросе — повторит вопрос через 2 часа (`SNOOZE_MINUTES`).

### Анализ в нейросети

Выгрузите дневник (`.md`) и отправьте файл в ChatGPT / Claude / Gemini с просьбой, например:

> Проанализируй дневник головной боли: частота и сила приступов, возможные триггеры, связь с менструальным циклом, эффективность обезболивающих, сколько дней в месяц принимались обезболивающие. Что стоит обсудить с неврологом?

Нейросеть — не врач: результат стоит обсудить со специалистом.

## Настройка вопросов

Вопросы лежат в [`questions.yaml`](questions.yaml) — их можно менять, добавлять и удалять без правки кода. Типы: `single` (один вариант), `multi` (несколько), `scale` (шкала чисел). После правки:

```bash
docker compose restart
```

Не меняйте `id` у вопросов, на которые уже есть ответы, — иначе в выгрузке старые ответы потеряют подпись.

## Все параметры `.env`

| Параметр | По умолчанию | Описание |
|---|---|---|
| `BOT_TOKEN` | — | Токен от @BotFather (обязательно) |
| `ALLOWED_USER_IDS` | — | Telegram ID через запятую, кому разрешено пользоваться |
| `WHISPER_MODEL` | `medium` | `tiny` / `base` / `small` / `medium` / `large-v3` / `off` |
| `WHISPER_LANGUAGE` | `ru` | Язык голосовых |
| `WHISPER_UNLOAD_MINUTES` | `10` | Через сколько минут простоя выгружать модель из памяти |
| `NOTES_AUTOCLOSE_MINUTES` | `60` | Автозакрытие записи, если не нажали «Готово» |
| `SNOOZE_MINUTES` | `120` | Через сколько повторить опрос после «Спроси позже» |
| `TZ` | пояс сервера | Например `Europe/Moscow` |

У каждого пользователя из `ALLOWED_USER_IDS` свой отдельный дневник и свои настройки опросов.

## Обслуживание

```bash
docker compose logs -f --tail 100   # логи
git pull && docker compose up -d --build   # обновление
```

Бэкап — это просто папка `data/` (база в `data/diary.sqlite3`, ежедневные копии в `data/backups/`).

## Запуск без Docker

```bash
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
set -a && . ./.env && set +a
python -m bot.main
```

## Устройство

```
bot/
  main.py        — запуск, регистрация обработчиков
  handlers.py    — диалог: опросы, вопросы, заметки, настройки, выгрузка
  schedule.py    — расписание опросов, автозакрытие записей, бэкапы
  transcribe.py  — расшифровка голосовых (faster-whisper, ленивая загрузка)
  export.py      — выгрузка в Markdown и CSV
  db.py          — SQLite
  questions.py   — чтение questions.yaml
  config.py      — настройки из .env
```
